# curobo_certify

Research campaign for continuous certification of unchanged cuRobo TimeOpt trajectories.

The initial implementation plan, GPT-6 Luna handoff, offline interactive HTML report and report tests are maintained on [exp/certification-campaign-plan-20261110](https://github.com/pkicki/curobo_certify/tree/exp/certification-campaign-plan-20261110).

No GPU campaign results are available yet. The report clearly distinguishes analytic illustrations from future measurements.
