# Repository working agreement

This is a research campaign, initially a plan and report prototype. Read docs/CAMPAIGN_PLAN.md and docs/PROGRESS.md before implementation.

- Preserve TimeOpt outputs in Phase A. Certificate subdivision changes representation only.
- Keep proof-backed certification, numerical bounds, sampled diagnostics and analytic illustrations visibly distinct.
- Never promote partial kinematic certification to a full torque/torque-rate certificate.
- Record exact source/config/input hashes and all failed or inconclusive cases.
- Use a research branch; commit completed packages. Do not create PRs or merge unless the user later asks.
- Follow the campaign's staged correctness gates. Update the plan when commands or formats change.
- Avoid copying private datasets or upstream implementation into this public repository without the appropriate provenance and license handling.
- The browser demo is not a production numerical or interval-certification implementation.
